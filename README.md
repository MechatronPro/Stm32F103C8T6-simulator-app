# STM32F103C8T6 Simulator 🔵💻

> **FIRST BUILD LAUNCH - v1.0**

A powerful **OFFLINE simulator** for the STM32F103C8T6 (Blue Pill) microcontroller board. No internet needed, no hardware needed.

### What is this?
This app lets you simulate your STM32F103C8T6 projects on your PC without the real board. Perfect for students, hobbyists, and developers.

### ✨ Features in this First Build
- ✅ STM32F103C8T6 Core Simulation
- ✅ GPIO Simulation
- ✅ Timer & PWM Simulation
- ✅ USART / I2C Basic support 
- ✅ 100% Offline - Works anywhere
- ✅ Lightweight & Fast

### ⚠️ Current Limitation
**DMA (Direct Memory Access) is NOT supported in this first build.** This is a known limitation of v1.0.
